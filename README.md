# Ethereal Arena

網頁版雙人連線卡牌遊戲，TypeScript + Vite。畫面固定 16:9（以 1920×1080 為基準，會自動縮放）。

## 怎麼玩

**最簡單：** 直接用瀏覽器打開 `docs/index.html`（已經打包好的版本），雙擊就能玩。

**開發模式（改程式會即時更新）：**

```bash
npm install
npm run dev      # 開 http://localhost:5173
npm test         # 跑規則測試（含 2000 場隨機對打）
npm run build    # 重新打包到 docs/
```

大廳有四種模式：

| 模式 | 說明 |
|---|---|
| 建立房間 | 產生 6 位數房號，把房號給對手；對手加入後雙方各自選角 |
| 加入 | 輸入對方的房號 |
| 對戰電腦 | 你選隊伍，電腦隨機組隊、隨機出牌（測規則用） |
| 本機雙人 | 玩家一、玩家二輪流選角，同一台電腦輪流操作，畫面會跟著輪到的人翻轉 |

每種模式開打前都會進**選角畫面**：點角色加入隊伍（先點的在左邊，可以交換左右），右邊會顯示能力和完整牌組。連線時雙方各自選、看不到對方選誰。

### 連線方式

用 [PeerJS](https://peerjs.com/) 做端對端（P2P）連線：房主的瀏覽器負責跑遊戲規則，對手只送操作過去，所以**不需要自己架伺服器**。
配對時會用到 PeerJS 免費的公開配對伺服器。少數網路環境（例如某些手機網路）可能連不上，之後如果常發生，可以再加 TURN 伺服器或改成自架伺服器。

## 換上圖片

圖片放在 `public/assets/`，打包時會複製到 `docs/assets/`，沒放圖時會顯示佔位圖。開遊戲時會先預載所有圖片（有進度條），之後畫面和動畫都不會閃。
圖片格式是 WebP：生圖 AI 的原圖（PNG）用 `python scripts/optimize_images.py` 轉換，會縮成實際需要的大小（31 張圖約 2.6 MB）。
每個角色有一套統一規格的圖：立繪 `chars/`、卡圖 `cards/`、卡背 `backs/`（詳見提示詞檔的「卡背」；卡面由遊戲畫，不用底框圖）。
檔名和 AI 生圖提示詞都在 [`圖片提示詞.md`](./圖片提示詞.md)。

## 程式結構

詳細的架構、慣例、新增角色的步驟都在 [`AGENTS.md`](./AGENTS.md)（給一起協作的 AI 和人看）。簡單來說：

```
src/engine/   遊戲規則（純邏輯，跟畫面完全分開）
  chars/      每個角色一個檔；新角色在 chars/index.ts 登記
src/net/      本機、電腦、PeerJS 連線
src/ui/       畫面：render（畫）、anim（動畫）、input（操作）、popups、lobby
src/styles/   樣式，依畫面區塊分檔
src/config.ts 預設隊伍等設定
test/         規則測試、每個角色的測試、隨機對打壓力測試
```

## 規則實作備註

規則依照討論結果實作，下面這些是規則沒寫到、我先自己決定的地方，要改跟我說：

- 卡牌上的「打擊」傷害 = 使用者的 AT（薩凡娜是 1）
- 「-X TP」類效果（週轉、武裝千金）對瀕死單位也有效，可以直接把瀕死單位處決
- 重創的 -3 HP 是直傷，不吃負傷 +1
- 被救治的角色當回合不能行動，TP 維持瀕死時剩下的數值
- 被棄置的牌先 +1 財富，再結算它的「(棄置時)」效果，所以那 1 點財富可以拿來發動同一張牌的收買
- 雙方都用兩隻薩凡娜時，任一隻棄牌，兩隻都會 +1 財富
- 恕不退款（沒收買）：TP 照扣、重創照樣觸發，只是受傷不會 +1
- [洗牌]＝能力或卡牌效果把棄牌區洗回牌組後，再抽 1 張（專案擁有者確認）；武裝千金的我方全體洗牌是兩隻各抽 1 張，[瀕死]的角色只洗不抽；牌組抽完自動洗回不算[洗牌]

### 葛蘭妮

- 「我方棄牌」包含隊友棄的牌，所以葛蘭妮可以吞掉薩凡娜的牌；吞噬後抽 1 張的是葛蘭妮
- 吞噬的牌用掉（能力 4）或消化（能力 5）後，進的是**葛蘭妮的**棄牌區，之後會被洗進葛蘭妮的牌組
- 葛蘭妮用到別的角色的牌時，那張牌的專屬機制（例如薩凡娜的收買）因為沒有財富而不會發動
- 盤中餐、食肉的「吞噬 1 張牌」可以從我方任一角色的手牌選（兩副手牌一起高亮，直接選；專案擁有者要求不要先問「選誰的」）
- 覓食的「本回合已棄過牌」只要我方任一角色這回合棄過牌就算
- 消化時把牌放進棄牌區不算「棄牌」（不會觸發暴食本能、財富）
- 吞噬的牌雙方都看得到
- 飲血回復的量 = 這次打擊對 HP 造成的傷害（打瀕死單位時是 0）

### 薩維爾

- [直擊]＝造成傷害、但**不減少對方 TP**（所以也不會打出[負傷]）；對[瀕死]單位仍會照常扣 TP，否則薩維爾永遠無法[處決]對手
- [直傷]（通緝令、餘燼的額外傷害）直接扣 HP，不吃[負傷]增傷和減傷，不會觸發 TP 相關規則；臨時 HP 也算 HP，會先被扣（專案擁有者確認）
- [主動攻擊]花 0 AP、改消耗 1 [焰能]；[焰能] 層數＝本回合還能主動攻擊幾次（上限 6 層），回合結束清空
- 沒有[焰能]時完全不能主動攻擊，要靠瞬焰、裝填先累積
- [連擊] 計數：每一次[打擊]都算 1 次（主動攻擊、卡片打擊、多段打擊的每一段都算）；打出卡片本身不算
- [連擊 3、4、5] 是「該次打擊結束後」給下一次攻擊 +1 AT，不可疊加；[連擊 6] 是「第 6 次打擊」那一次傷害 ×2（火輪擊的固定傷害也一樣 ×2）
- 瞬焰、裝填、通緝令的[連擊 X] 判斷，用的是「打出這張牌當下已經攻擊過幾次」
- 速拔的「下回合 -1 AT」直接改對方 AT，並記在對方身上，於薩維爾**下一個自己回合開始**時恢復；薩維爾若在這之前死亡就不會恢復
- 火神的通緝令只能指定敵方單位；標記在該單位身上，薩維爾回合結束時清掉
- 火神的通緝令（[連擊 0]）與薩達莉亞的餘燼的 +AP 可以超過 AP 上限
- 通緝令、餘燼的額外[直傷]不算一次攻擊，不會推進[連擊]
- 為了讓「每回合多次主動攻擊、且改用專屬資源付費」能在角色檔完成，核心新增通用 hook：`attackLimit`、`attackApCost`、`canAttack`、`onAttack`、`strikeOpts`、`onAttackHit`，以及 `strikeOnce/strike` 的 `direct`（直擊）、`power`（指定傷害）選項；核心沒有出現任何角色 id 判斷

### 拉尼斯

- [墬淵]：永久、不可疊加，最大 TP -1；目前的 TP 也會一起降到新上限，之後回合開始回滿、[瀕死]回滿、[負傷]判斷都用新的上限
- [洗牌]照共用詞條的定義：只有「能力／卡牌效果造成的洗牌」才算，牌組抽完自動洗回不算、也不會觸發能力 1
- 能力 1 的「AT 1 的[打擊]」是固定 1 點傷害＋-1 TP，不是拉尼斯的 AT 8；每回合最多 3 次，自己的回合開始時歸零
- 能力 1 只要**我方任一角色**[洗牌]都會觸發（和葛蘭妮的「我方棄牌」一樣）
- 能力 2：她所有「指定 1 名敵方單位」都只能選[墬淵]單位，也不受 SP 限制；場上沒有[墬淵]敵人時，普攻與需要指定敵人的牌都不能用（效果直接不發動）
- 能力 3：敵方單位進入[重創]就給[墬淵]，包含被她的效果打成[重創]；同一單位不疊加
- 能力 4：自己的回合結束時自動詢問，可選 0～3 張；手牌[移除]至棄牌區後，再從牌組**最上面**[移除]同樣數量至棄牌區（專案擁有者確認：移除＝丟到棄牌區）。都不算棄牌，不觸發棄牌相關的被動和(棄置時)
- 「移除 N 張牌至棄牌區」＝從牌組最上面拿 N 張進棄牌區：不算抽牌、不算棄牌、不觸發[洗牌]；牌組不夠就只移除剩下的
- 卡牌上「抽出此牌時」改成共用的「(抽出時)」寫法（`drawText`，和(棄置時)同一套），在抽到的當下就結算（含開局抽牌）；之後才打出去時不會再檢查棄牌區
- 正規化（專案管理）：「墬淵」是專案擁有者刻意用的字，保留；記事的錯字（不詳→不祥）修正；卡面文字統一成「N 點[直傷]」「≥」等寫法；瀆神海域的文字照實作改寫成「下一個陷入[重創]的單位額外受到 3 點[直傷]」；「移除 N 張至棄牌區」「移出牌局」改成共用詞條
- 瀆神海域：任一單位（雙方都算）陷入[重創]時額外受 3 點[直傷]，結算一次後效果就結束；順序是先扣[重創]本身的 -3，再扣這 3
- 黑漩、瀆神海域的「自身[洗牌]」照共用詞條：棄牌區洗回牌組後抽 1 張，也會觸發能力 1 的掃場
- 血叉的「上回合有[重創]」＝該單位自己上一個回合開始時是否處於[重創]
- 深淵巨口的「已損失生命一半」以最大 HP 計算、無條件進位；「指定的單位是[瀕死]單位」＝使用時就已經[瀕死]（專案擁有者確認），被這張牌打進[瀕死]不算；處決後回復自身 10 HP；這張牌用完直接移出牌局
- 能力 2 讓拉尼斯在敵方沒有[墬淵]單位時無法普攻、指定敵人的效果落空：這是設計（專案擁有者確認），她靠[洗牌]掃場造成傷害、靠隊友把敵人打進[重創]
- 為了這些機制，核心新增通用欄位／函式：`tpMaxDown`（永久最大 TP 減少，`g.effTpMax` 讀）、`removed`（移出牌局的牌）、`g.mill`／`g.removeHandCards`／`g.removeDeckTop`；通用 hook：`enemyTargets`（改用別的指定規則）、`onAllyShuffle`、`onUnitCritical`、`onOwnTurnEnd`；卡牌欄位：`onDrawCard`、`removeAfterPlay`；還有 `registerStatus`（掛在單位身上的共用狀態，畫面自動顯示徽章）。核心沒有出現任何角色 id 判斷

### 米雅

- [聖環]的「自身場上只能有一個」＝**我方場上同時只能有一個**（專案擁有者確認）：聖旨給新的，隊友身上原本的臨時[聖環]就移過來；隊友有永久[聖環]時聖旨不能用；不公之恩寵的永久[聖環]一定給得出去，會取代隊友身上原本的[聖環]（專案管理決定）
- [聖環]「受到治療時回復 1 HP」直接加在該次治療量上（治療 3 → 回 4），不會多出一次治療事件；同一張牌對同一個單位只算一次治療（例如渙散祈禱對[聖環]單位是 1＋2＝3，再加 1，共 4）（專案管理正規化）
- [聖環]「自身回合結束回復 1 HP」在該單位擁有者的回合結束時結算，狀態在單位身上、不受米雅是否存活影響；這次回復不套用聖環自己的治療加成，但會觸發米雅的能力 3
- [聖環]「回合開始後解除」＝該單位擁有者的下一個回合開始時解除；永久[聖環]不會解除
- 能力 1：米雅的[救治]不限次數，也不佔用、不消耗一局一次的救治額度（隊友之後仍然可以救治米雅）
- 能力 2【聖旨】花費 2 AP，只能選「還沒有[聖環]」的我方單位（隊友的[聖環]會移過來）
- 能力 3：每回合（我方回合）第一次**實際**回復 HP 時抽 1 張，滿血不算；[聖環]的回合結束回復也算；每回合只抽一次，自己的回合開始時歸零
- 能力 4：只看隊友（另一個單位）有沒有[聖環]（永久也算），有就 SP -1，SP 可以到 -1
- 聖雅嘆息的「上回合有[負傷]」＝該單位自己上一個回合開始、TP 回滿之前的狀態（核心新增 `woundedPrev`，和[重創]的 `criticalPrev` 同一個時機記錄）
- 告罪：-2 AT 直接改目標的 AT，記成目標身上的[告罪]狀態（畫面有徽章），在**目標自己的回合結束時**加回去＝撐到米雅的下一個回合；米雅中途陣亡也會照樣恢復（專案管理正規化，原本米雅死掉就不會恢復）；AT 最低到 0，實際扣多少就記多少
- 沒興趣的「直到下個自身回合」用核心既有的 `dmgReduce`（各單位自己回合開始時歸零）
- 麻煩死了的臨時 TP 用核心的 `tTp`（扣 TP 時先扣臨時 TP）；角色數值列會顯示「臨時 TP +N」
- 不公之恩寵：(1) 只能選我方單位；已經有臨時[聖環]的會升級成永久；「永久 +1 TP」＝最大 TP +1，目前 TP 也 +1。(2) 只在有[瀕死]隊友時出現，救治免費（不用付 HP／AP），和一般救治一樣以「TP × 2」的 HP 回歸（核心 `g.reviveUnit`），也不算、不消耗一局一次的救治，之後再回復 5 HP。(3) 我方全體 10 HP。使用次數記在米雅身上，第 2 次使用後[移出牌局]
- 數值沒給的 SP 先設 0（能力 4 會讓它變成 -1）；米雅**不能主動攻擊**（專案擁有者確認，`CharDef.noAttack`，畫面不顯示普攻按鈕）
- 為了這些機制，核心新增通用機制：`StatusDef.healBonus`（治療加成）、`StatusDef.onTurnStart`／`onTurnEnd`（掛在單位身上的狀態，在該單位擁有者的回合開始／結束時結算）、通用 hook `onAllyHeal`（我方單位實際回復 HP）與 `spDelta`（SP 加減）、`CharDef.rescueUnlimited`（不佔用一局一次的救治）、`removeAfterPlay` 可以寫成函式（依使用次數決定何時移出牌局）、`g.heal` 的 `raw`（不套用治療加成）、`g.rescueAllowed`、`Unit.woundedPrev`；核心沒有出現任何角色 id 判斷

- 規格寫「17 張牌」，但列出的張數加起來是 16 張（4＋3＋2＋2＋2＋2＋1）；照列出的張數實作，共 16 張，不補（專案擁有者確認）

- 「下 1 次[主動攻擊] -2 AP」記在角色身上，下一次主動攻擊時消耗，AP 花費最低 0
- 別想跑!!! 的「SP +1」給目標 `spBonus`（和[居前]同一個欄位，目標自己的回合開始時歸零）
- 承此亦死 的「X TP」＝目前最大 TP − 目前 TP，打出時先算好；「無條件指定」＝不受 SP 限制，可以選任一敵方單位（含[瀕死]）
- SP 規格沒給，先設 0；AT 基礎值 0（實際 AT 由能力 1 給）
- 為了這些機制，核心新增通用機制：`CharDef.rescueCost`（改寫[救治]花費）、`CharDef.unyielding`（[不屈]）、`CharDef.atText`（選角畫面的 AT 顯示文字）、通用 hook `onHpLoss`（損失 HP，含支付代價）、`onUnitWounded`（任一單位進入[負傷]）、`selfHit`（打擊自身的傷害），以及 `g.strikeSelf`、`g.gainTp`（回復 TP，會解除[重創]）、`g.payHp`（支付 HP 代價）、`g.canAct`、`g.rescueCost`；核心沒有出現任何角色 id 判斷

### 異端物

- 牌組 18 張照規格列出的張數（4＋4＋3＋3＋3＋1）
- 能力 1：卡牌費用改用 HS（手牌）支付，不花 AP（`CharDef.costAs: 'hand'`）；打出的那張牌本身不能拿來付自己的費用
  - 費用可以付自己的手牌，也可以付隊友的：兩副手牌一起高亮，直接混著選（不先問「從誰付」，專案擁有者確認）；能付的牌剛好等於費用時直接全付；核心 `g.playFromHand`，一般出牌和強制打出共用同一個流程
  - 付費的牌是[移除]（進棄牌區），不算棄牌，所以不會觸發棄牌相關效果，之後可以被【粉碎幻境】或洗牌拿回來
  - 選角畫面、卡面角標顯示「HS」，角色數值列顯示目前手牌數
- 能力 2：主動攻擊只移除**異端物自己的**手牌（不含隊友），對敵方**全場**造成等於移除張數的[直傷]（`g.dealHp`：不吃減傷、[負傷]增傷，也不扣 TP）；之後異端物本回合停止行動（`Unit.noActionTurn`，不能出牌、攻擊、[居前]、[救治]、發動能力，自己的下個回合開始解除）
- 能力 3：「我方每回合首次移除手牌」＝我方回合內第一批被移除的手牌（一次付清費用算同一批、掃場也算一批）；被移除的單位各抽回自己那批的張數，所以付隊友的牌就是隊友抽；每回合只觸發一次，自己的回合開始時重新計算；抽牌前先結算，掃場的傷害不會被抽到的牌影響
- 能力 4／5 的[異方侵入]、[超越此方]只能透過【臨界點的裁決】進入（牌組沒有獨立的型態卡）：一場只會選一種，之後不會再變
  - 付費的牌**多來自自身**→[異方侵入]；**多來自隊友**→[超越此方]（11 張不可能剛好各半）
- 【臨界點的裁決】的「回合開始時，如果滿足此牌條件，則直接打出」＝自己的回合開始、抽牌前，如果我方湊得出 11 張可以付的手牌（自己＋活著的隊友，不含這張牌本身）就強制打出；**付費和一般出牌一樣由玩家自己選**要移除誰的哪幾張（專案擁有者確認），所以型態由玩家決定；使用後[移出牌局]
- [異方侵入]：自己每個回合開始的[起手抽牌]改為 3 張（正常 1 張＋額外 2 張），在抽牌前就套用；同時解鎖[主動攻擊]
- [超越此方]：隊友每個回合開始的[起手抽牌]改成從牌堆**檢索** 1 張（不抽牌），由隊友自己選、選完洗牌；檢索不是抽牌，不觸發(抽出時)
- 能力 5 的「最大 HP 設為 20」＝異端物最大 HP 改成 20，目前 HP 超過就降到 20；「HP 與隊友綁定」＝任一方受到傷害、支付 HP 時另一方也受到同一次傷害，回復 HP 時另一方也回復同樣的實際量（各自套用自己的減傷／臨時 HP／最大 HP）；綁定後異端物可能比隊友先倒下，倒下後連結就不再作用
- 「TP 以隊友為基準」＝異端物的 TP 跟著隊友：每次任一方 TP 增減、或隊友回合開始回 TP 後，異端物的 TP 與最大 TP 都同步成隊友的數值（異端物自己掉 TP 也會被蓋回去）
- 「隊友最大 TP +2、+1 AT」＝只加最大值（目前 TP 不變，和利利安特能力 2 同一種寫法）、AT 直接 +1
- 【侵入】＝自身抽 1 張；【超越】＝隊友抽 1 張
- 【撕裂現實】：我方任一單位 SP +1、受到傷害 -1，直到該單位自己的下個回合開始；這是效果造成的[居前]，不花 AP、也不佔用該單位本回合的[居前]
- 【粉碎幻境】：我方每名單位各自從**自己的**棄牌區檢索 1 張（同名的牌只列一次），所以兩邊可以各拿 1 張；之後我方全體各回復 3 HP
- 【欲望與解析】：指定自身時，隊友失去 6 HP（HP 損失、不是傷害，可打進[瀕死]；有 HP 綁定時異端物也會跟著扣），異端物回復 6 HP、抽 1 張；指定隊友時，該單位抽 1 張、[洗牌]（照共用詞條再抽 1 張）、獲得[臨時TP] 2
- 數值沒給的 SP 先設 0；AT 基礎值 0（實際傷害由掃場的移除張數決定）
- 為了這些機制，核心新增通用機制：`CharDef.costAs`（手牌費用）、`CharDef.attackCostText`（普攻按鈕文字）、`Unit.hpLink`／`tpLink`／`noActionTurn`、`g.handRemoved`（一批手牌移除後通知我方）、`g.searchDeck`／`g.searchDiscard`（檢索）、`CardDef.play` 的支付明細、通用 hook `attack`（自訂整個主動攻擊流程）、`turnStartDraw`（起手抽牌張數）、`onAllyStartDraw`（取代我方單位的起手抽牌）、`onHandRemoved`；核心沒有出現任何角色 id 判斷
- 能力 5 的「HP 與隊友綁定」＝兩邊各自受到同樣的傷害、回復同樣的量（專案擁有者確認：「掉同樣的血」）；「TP 以隊友為基準」採即時同步隊友 TP（含最大 TP）；臨界點的「滿足此牌條件」採「湊得出 11 張手牌」
- 手牌費用一律由玩家打出後先選要付哪些牌（自己或隊友的），手牌不夠就不能打出（專案擁有者確認）

### 八重

- 牌組 17 張照規格列出的張數（4＋2＋2＋2＋2＋2＋2＋1）
- 「攻擊」＝1 次[主動攻擊]（普攻），或打出 1 張攻擊牌，各算 1 次（無念斷打全體也只算 1 次）；[拔]、[破] 追加的直擊／直傷不算新的攻擊
  - 攻擊牌＝卡名旁有武器標記的牌：三合（刀）、真鳴（槌）、長歌（弓）、無念斷（太）、赤山（斧）。標記用共用的 `CardDef.tag`，有 tag 的牌就是攻擊牌，卡面會顯示成小標籤
- 普攻和攻擊牌走同一套核心新增的通用「攻擊」流程（`g.beginAttack`／`g.attackStrike`／`g.endAttack`＋通用 hook `onAttackStart`／`onAttackEnd`），核心沒有出現任何角色 id 判斷
- 能力 1（[拔]）：每次攻擊（普攻也算）先把牌堆最上方 1 張牌[移除]至棄牌區，套用那張牌的[拔]；牌堆空了就不翻、也沒有[拔]，不會自動洗牌
  - 傷害前的修正（「本次傷害為[直傷]」、+AT）在翻牌時就套用到這次攻擊；追加[直擊]／[直傷]、回復 HP、-TP 在主要傷害之後結算
  - [拔]／[破] 追加的[直擊]用八重原本的 AT，不含三合的「本次傷害 -1 AT」或無方的「+3 AT」
- 能力 2（[破]）：每個自己回合的第 3、6、9…次攻擊觸發[破]，次數在自己的回合開始時歸零；同一次攻擊最多觸發一次
  - 泰坦之心／無方(3) 的「下一次攻擊觸發[破]」是額外的觸發（角色計數器），不影響次數
  - 普攻的[破]＝能力 5 的豪破
- 能力 3（架勢）：花 1 AP，選 1 張自己的手牌放到牌庫頂（`g.putHandOnDeckTop`，不算棄牌、也不算[洗牌]），每回合不限次數
- 能力 4（一心）：回合開始時有手牌就不抽（`turnStartDraw` 回傳 0），沒有手牌才抽 1 張
- 能力 5（豪破）：普攻觸發[破]時 +3 AP，可以超過 AP 上限
- 八重回復 AP 一律直接加在 AP 上，可以超過 AP 上限（和薩維爾的 +AP 一樣；AP 上限只是回合開始的回復上限）
- 【泰坦之心】：抽 1 張牌、下一次攻擊觸發[破]；沒有[拔]
- 【三合】：本次傷害 -1 AT；[拔]追加 1 次[直擊]、[破]追加 2 次[直擊]
- 【真鳴】：打擊後支付自身 2 HP（`g.payHp`：是 HP 損失、可以打進[瀕死]，不是受到傷害），[拔]目標 -2 TP、[破]目標 -3 TP；自身 -2 HP 排在攻擊結算（含[拔]、[破]）之後
- 【長歌】：打擊後[移除] 1 張自己的手牌（玩家選、進棄牌區、不算棄牌；沒手牌就跳過），排在[拔]／[破]的追加傷害之後；[拔]追加 1 點[直傷]、[破]追加 3 點[直傷]
- 【備】：抽 2 張牌、+1 [臨時TP]；沒有[拔]
- 【無念斷】：[打擊]全體敵方單位後抽 1 張牌；[拔]這次傷害改為[直傷]（固定傷害：不吃[負傷]增傷和減傷、不扣 TP），[破]同樣是[直傷]且 +2 AT。對[瀕死]單位用[直傷]不會扣 TP（照薩維爾[直傷]的慣例）
- 【赤山】：可以選敵方或我方任一**活著**的單位（不含自己）；選敵方時照一般 SP 限制，選隊友不受限。本次傷害 +1 AT；[拔]回復這次攻擊實際造成的 HP 傷害，[破]再回復同樣的量並再 +1 AT（兩個都觸發就回復兩次，回復量各自以當下 HP 上限為準）
- 【無方】：+5 AP、自身 -2 TP（TP 損失，會照一般規則觸發[負傷]／[重創]），然後選 1 項：
  - (1) 下一次攻擊[拔]翻到的牌觸發 3 次（三合＝追加 3 次[直擊]、赤山＝回復 3 倍傷害量、真鳴＝-6 TP）
  - (2) 下一次攻擊 +3 AT（只加在主要傷害上，不含[拔]／[破]追加的[直擊]）
  - (3) 選自己手牌裡最多 2 張攻擊牌，各自費用 -1 AP（記在那張牌上，打出前一直有效），並讓下一次攻擊觸發[破]；沒有攻擊牌時這項不出現
  - (4) [處決] 1 名[瀕死]的敵方單位（不受 SP 限制）；沒有[瀕死]敵人時這項不出現
  - 之後自身[洗牌]（照共用詞條：棄牌區洗回牌組再抽 1 張），再選 1 張手牌放到牌庫頂（沒手牌就跳過）
  - 無方自己的[拔]：回復 2 AP
- 角色數值列會顯示本回合攻擊次數（「攻擊 2／3」）、下次攻擊[破]、下次[拔]×3、下次AT 這些待生效的效果
- 為了這些機制，核心新增通用機制：`CardDef.tag`（武器標記＝攻擊牌）、`CardInst.costMod`（單張牌的費用修正，`g.cardCost` 會讀）、`AttackCtx` 與 `g.beginAttack`／`g.attackStrike`／`g.endAttack`（普攻與攻擊牌共用的攻擊流程）、`strikeOnce` 的 `fixed`（[直傷]）、`g.millTop`（回傳被移除的牌）、`g.putHandOnDeckTop`、`g.chooseCardsFrom` 的篩選參數，以及角色計數器的 `max`／`onlyPositive` 顯示；核心沒有出現任何角色 id 判斷
